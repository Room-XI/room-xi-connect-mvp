# KPI Definitions
- Daily Check in Rate = daily_checkins / DAU
- 7 day Streak Completion = users with 7 consecutive check ins / active users
- Explore Unlock Compliance = users who unlock Explore by 10 00 local / active users
- Opt in Rates = share_orb_on + geo_on + research_opt_in
- Staff Weekly Dashboard Use = staff with >= 1 dashboard session / total staff
- Referral Conversion = program page views to sign ups (%)
- Crisis Routing = time from keyword detection to support link click (median)
