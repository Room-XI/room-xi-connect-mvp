Core design values:

2️⃣ Visual Architecture

Element	Finalized Behavior
7-Day Gradient Core	Always displays all six hues — Cold, Stormy, Foggy, Clear, Breezy, Aurora — blended into a single orb. The proportion of each hue reflects its frequency over the last 7 days.

3️⃣ Functional Logic
	1.	Data Input → Youth performs one mood check-in per day.
	2.	Storage → System saves mood + timestamp + (optional geo hash + noise) + 7-day array.
	3.	Processing → ratio = mood_count / 7; color weight scaled to opacity 0.3–0.9.
	4.	Visualization → Orb shader generates weighted radial gradient.
	5.	Settle Loop → Tween interpolates toward new ratios for 10–12 minutes.
	6.	Analytics → Only weekly summaries stored for aggregate dashboards.
