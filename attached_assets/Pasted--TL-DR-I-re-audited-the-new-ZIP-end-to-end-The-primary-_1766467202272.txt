## Fix-Now issues (with impact)

1. **Privacy Center write calls lack CSRF header**

   * **Symptom:** “Failed to update privacy setting. Please try again.”
   * **Cause:** `PUT /api/privacy/consents` and `POST /api/privacy/reminder-response` used raw `fetch`. `/api/privacy/*` is mounted with `validateCsrfToken`.
   * **Fix:** Switch both to `fetchApi(...)` (it fetches `/api/auth/csrf-token` and injects `X-CSRF-Token`). I provided a literal diff replacing raw `fetch` with `fetchApi`.

2. **Must be authenticated for privacy endpoints**

   * **Symptom:** Same error when logged out (server responds `401 Not authenticated`).
   * **Fix:** In `PrivacyCenter.tsx`, if `api.privacy.getConsents()` or `updateConsents()` returns 401, redirect to `/auth/login` with a toast (“Please sign in to manage privacy”). That prevents generic failure messages.

3. **CORS allowlist**

   * **Symptom:** Writes fail on prod/staging origins with 403 preflight → user sees a generic failure.
   * **Cause:** `server/middleware/cors.ts` only allows `capacitor://localhost` + `http://localhost` unless `ALLOWED_ORIGINS` is set.
   * **Fix:** Set `ALLOWED_ORIGINS=https://app.yourdomain,https://staging.yourdomain`.

4. **API origin mismatch**

   * **Symptom:** Client calls 404/Network error (especially on Vercel static + separate API).
   * **Cause:** `src/lib/config.ts` defaults `API_BASE` to `window.origin + /api`.
   * **Fix:** For separate API host, set `VITE_API_BASE=https://api.yourdomain/api` at build time (and in Replit env).

5. **Email provider configuration (consent/guardian)**

   * **Symptom:** Guardian verification/invite emails don’t send (or server fails `verifyEmailConfig`).
   * **Cause:** Missing `EMAIL_PROVIDER` + provider creds.
   * **Fix (pick one):**

     * Gmail: `EMAIL_PROVIDER=gmail`, `GMAIL_USER`, `GMAIL_APP_PASSWORD`
     * SendGrid: `EMAIL_PROVIDER=sendgrid`, `SENDGRID_API_KEY`, `EMAIL_FROM`, `EMAIL_FROM_NAME`
   * **Also set:** `PUBLIC_BASE_URL=https://app.yourdomain` so email links open the right host.

6. **Sessions & DB basics**

   * **Symptom:** Login looks fine but subsequent API calls act “not logged in” or fail randomly; writes crash.
   * **Cause:** Missing `DATABASE_URL` or `SESSION_SECRET` (Express session uses Postgres store).
   * **Fix:** Set both; ensure the DB is reachable from Replit/host.

7. **DB migrations for privacy tables**

   * **Symptom:** 500 “Failed to update privacy settings” even with CSRF/auth correct.
   * **Cause:** Tables not created (`privacyConsents`, `youthPrivacySettings`, `consentAuditLog`, `consentReminders`, etc.).
   * **Fix:** Run Drizzle migrations before boot: `npm run db:migrate`. Seed only if needed.

8. **Notifications toggle (optional)**

   * **Symptom:** Toggling notifications fails (if you wired it to server push).
   * **Cause:** Missing `VAPID_PUBLIC_KEY` or server push config.
   * **Fix:** Provide valid VAPID keys, or gate the toggle behind a feature flag when unset.
