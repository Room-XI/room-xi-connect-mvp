## Overview
Room XI Connect is a youth mental health and wellness application (ages 13-25) designed to provide daily mood check-ins, local program discovery, crisis support, and an AI companion named Ximi. The project aims to empower youth by connecting them with resources and community, with a strong focus on privacy-by-design and a "programs-first" approach. It currently serves over 570 youth through local programs and pilots, emphasizing universal intake, program discovery, and robust crisis support.

## System Architecture
### UI/UX Decisions
The application features a youth-friendly landing page, a separate professional "About" page for stakeholders, and a "programs-first" experience allowing unauthenticated users to browse resources. Authentication is smart, prompting sign-in only for authenticated features. UI adapts for guests versus authenticated users. A 6-level mood scale with HSL color gradients is used for mood tracking, and a two-layer, legally compliant consent system (Alberta PIPA & HIA) with granular toggles is implemented, avoiding gamification.

### Technical Implementations
The tech stack includes React 18 with TypeScript, Vite 5, React Router v6, Tailwind CSS for the frontend, and Supabase (PostgreSQL, Auth, Storage) for the backend. Key features include daily mood tracking with DST-safe streak logic (Luxon), a trauma-informed AI companion (Ximi) with dual personality modes and real-time crisis detection, QR code attendance tracking, offline support via IndexedDB, and end-to-end encryption for sensitive data. Deployment is configured for Replit, and the database schema includes tables for wellness dimensions, Ximi conversations, guardian verifications, health profiles, consent events, breach events, and consent reminders. Geo-spatial privacy is ensured using H3 Hex Bucketing with dual k-anonymity thresholds and Laplace noise. High-contrast accessibility mode is implemented via `@media (prefers-contrast: more)` for enhanced visibility.

**Mood Orb Enhancements (Nov 2025):** The 7-day canvas-based gradient mood orb features a smooth, dreamy pastel aesthetic matching the app's trauma-informed design. Implementation includes: pixel-perfect canvas rendering with circular HSL color interpolation ensuring all 6 moods always visible via epsilon weighting, 50px Gaussian blur for ultra-soft atmospheric blending, 25% saturation reduction and +10 lightness for gentle pastel tones, sigma=π/2 angular blending for seamless color transitions, enhanced radial fade for dimensional depth, HiDPI/retina display support with device pixel ratio handling, per-day mood aggregation with Variability Index and Consistency Index analytics, ambient page background tint, privacy-safe PNG export via html2canvas, accessibility features (high-contrast mode, pattern overlays, color key drawer), automatic refresh after check-in, and 30-day historical timelapse browsing. Server configured with `trust proxy` for accurate rate limiting.

**Admin Dashboard (Nov 2025):** A comprehensive admin dashboard provides real-time analytics and monitoring capabilities. Features include role-based access control via `profiles.isAdmin` boolean, live statistics widgets (total users, daily check-ins, program engagement, Ximi conversations), Recharts visualizations with 30-day trend analysis, audit log viewer with pagination and filters, and backend API endpoints with optimized SQL queries. All routes enforce admin authorization with 403 responses for non-admin users.

**Push Notifications (Nov 2025):** Complete Web Push API implementation enables browser-based push notifications with graceful degradation. System includes subscription management backend with `push_subscriptions` table, NotificationSettings component for user permission control, scheduled 8 AM daily check-in reminders via scheduler integration, service worker push event handlers for displaying notifications, and full error handling that degrades gracefully when VAPID keys are not configured (returns 503 responses without crashing). VAPID keys must be generated with `npx web-push generate-vapid-keys` and added to environment variables for production use.

**Voice/Text Journal Interface (Nov 2025):** Web Speech API integration provides accessible voice input and text-to-speech capabilities for journal entries. Implementation includes `useSpeechControls` hook with decoupled browser capability detection (separate `isDictationSupported` and `isPlaybackSupported` flags), VoiceControls component with input (microphone) and playback (speaker) modes, privacy-compliant messaging about browser cloud services, automatic transcript appending with proper state reset handling, Safari compatibility (TTS works even without speech recognition), keyboard accessibility (Space to toggle, ESC to cancel), and respect for `prefers-reduced-motion` accessibility preferences. Voice processing uses browser APIs locally where possible.

**Capacitor Mobile Wrapper (Nov 2025):** iOS and Android native app wrapper implemented via Capacitor 7 with bundle ID `com.roomxi.connect`. Configuration includes dynamic imports for all native plugins to preserve PWA compatibility, splash screen with 2-second duration and #1e293b background, status bar styling (dark style with theme-matched colors), haptic feedback utility with 6 interaction types respecting reduced-motion preferences, mobile permissions (iOS privacy strings for microphone/camera, Android manifest permissions), platform detection utilities (`isNativePlatform()`, `isIOS()`, `isAndroid()`, `isWeb()`), and reproducible native project generation via `npm run setup:mobile`. Native `/ios` and `/android` folders are gitignored with comprehensive MOBILE_BUILD.md documentation for regeneration. App icons and splash screens can be generated using `@capacitor/assets` CLI tool with 1024x1024 master icon and 2732x2732 splash image.

### Feature Specifications
The application utilizes a 6-level mood system and SAMHSA Wellness Dimensions. Ximi AI includes consent gating and crisis keyword detection. A legally compliant consent system involves a basic consent layer during account creation and a second layer for a "Safety Profile" with optional health information and granular media consent. A breach notification system is in place for OIPC compliance. Authenticated users must complete a daily check-in by 8 AM (Edmonton time) before browsing programs, a feature managed by an "Explore Gate." Ximi proactively supports users during mood declines based on a statistical mood variance detection service.

**Ximi AI Consent System (Nov 2025):** A dedicated consent flow for Ximi AI requires explicit user opt-in before accessing the AI companion. The XimiConsentModal displays comprehensive information about what Ximi is, how it works (AI-powered conversations, crisis detection, privacy-first design), and what users are consenting to (AI-generated responses, conversation storage, OpenAI API processing, crisis keyword detection). When users attempt to chat without consent, the modal automatically appears and preserves their message, automatically sending it after consent is granted for a seamless experience. Users can enable/disable Ximi anytime via a toggle in Settings. Backend enforcement ensures all `/api/ximi/chat` requests require `ximiConsent=true` in the user's profile, returning 403 errors otherwise.

- **Zeffy:** Donation platform.
- **Nodemailer:** Used for sending guardian verification emails via Gmail SMTP.
- **h3-js:** H3 hexagon geo-spatial indexing library.
- **html2canvas:** DOM-to-image library for mood orb PNG export.
